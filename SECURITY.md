# Security

This repository contains infrastructure and chaos-engineering examples intended for controlled test environments.

## Do not commit

Never commit:

- cloud credentials, access keys, tokens or private keys;
- customer or personal data;
- internal hostnames, private certificates or confidential configuration;
- proprietary company infrastructure or source code;
- production credentials or production connection details.

## Safe testing

Run experiments only in environments where you have explicit authorisation. Review target selection, IAM/RBAC scope, blast radius, monitoring, abort conditions and recovery before execution.

## Reporting a vulnerability

If you discover a security issue in this repository, please use GitHub's private vulnerability reporting where available rather than publishing sensitive details in a public issue.
